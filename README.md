# ועד עובדי פלאפון — עמוד נחיתה

עמוד נחיתה סטטי ורספונסיבי (HTML/CSS/JS), נבנה מקובצי PSD של העיצוב (דסקטופ + מובייל).

## תוכן
- `index.html` — מבנה העמוד
- `style.css` — עיצוב, מבוסס יחידת קנה־מידה פרופורציונלית (`--s`) לשמירה על יחסי ה־PSD
- `assets/` — תמונות, אייקונים, וידאו ופונט Ploni (`@font-face`)

## הרצה מקומית
```bash
python3 -m http.server 4173
```
ואז `http://localhost:4173/`.

## פיצ'רים
- Hero עם וידאו מוטמע במסגרת מה־PSD
- תפריט צדדי (המבורגר → X מונפש) עם קישורים
- פופאפים על אייקוני ההטבות
- פריסת מובייל נפרדת מ־PSD המובייל
